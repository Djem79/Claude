# План продвижения vs best practices 2026 — сверка и гэпы

**Дата:** 2026-08-04. **Метод:** внешний ресёрч (гайды Google, исследования GEO,
плейбуки digital-PR-агентств, гайды по Яндексу) → сверка с фактическим состоянием
кода и `docs/marketing/` → план-дополнение к [SEO-плану августа](./2026-08-01-seo-plan-august.md)
(не замена: августовский план построен на наших крон-данных и остаётся рабочим).

## 1. Что говорят источники (сжато)

**Google / контент.** Helpful Content влит в core-алгоритм; E-E-A-T — главный
фильтр, и читается он через **внешние** сигналы (кто ссылается/цитирует/упоминает),
а не самоописание. AI Overviews показываются в ~47–48% запросов и режут CTR
информационных выдач на 30–60% (Ahrefs, n=1.2M), но **цитируемые в AIO страницы
получают CTR-лифт**; 96% цитат AIO — из «верифицируемо авторитетных» источников.
Рецепт: прямой ответ в первых 50–70 словах, вопросные H2, свежесть ≤90 дней с
реальной проверкой цифр, **именованный автор с креденшелами + Person-схема**,
тематические кластеры с внутренними ссылками, оригинальные данные, которых больше
ни у кого нет. (surferseo.com 05.2026, pepper.inc 05.2026, digitalapplied.com 04.2026,
backlinko.com 02.2026)

**GEO / AI-поиск.** Три рычага по убыванию: структура (извлекаемые
ответ-капсулы 40–80 слов, таблицы, списки), авторитет (цитируемая статистика +
экспертные цитаты — два самых сильных фактора по исследованию Aggarwal et al.),
присутствие (быть в источниках, которым LLM уже доверяет: Reddit, обзоры,
каталоги, YouTube с транскриптами). Технически: не блокировать AI-краулеры,
llms.txt, SSR, entity-явность (полные имена вместо местоимений), dateModified.
**ChatGPT ретривит через Bing** → Bing Webmaster Tools обязателен. Perplexity
любит свежесть и Reddit. (okara.ai 06.2026, wetheflywheel.com 05.2026,
rightblogger.com 06.2026)

**Ссылки / digital PR.** 90%+ результативных кампаний — data-led: собственный
датасет → лендинг с методологией → питчи журналистам, которым эти данные нужны.
Остальное: реактивные комментарии (HARO/Qwoted/SOS), возврат безссылочных
упоминаний (unlinked mention reclamation — один из самых высоких ROI),
реверс-инжиниринг ссылок конкурентов, для недвижимости — локальные партнёрства.
Проверять dofollow-политику издания ДО питча. (outpaceseo.com 03.2026,
stellarseo.com 12.2025, sourcedeck.io 01.2026)

**Яндекс.** Поведенческие факторы, коммерческие факторы, региональность,
Яндекс.Бизнес/отзывы. **Для нас Яндекс-SERP — не канал**: сайт English-only для
международных инвесторов (мультиязык отклонён осознанно), русскоязычный спрос
обслуживают Дзен/TG/VK/OK — там дистрибуция, а не SEO. Из яндексовых практик
переносимы универсальные: поведенческие метрики, скорость, свежесть.

## 3. План-дополнение (сентябрь, поверх августовского)

Приоритет = эффект/усилие. Ничего из августовского плана не отменяется.

### A. Авторский слой E-E-A-T (нед. 1–2, ~1 день работы)
1. Страница `/about`-автора: Dzhambulat Tkhazaplizhev, Managing Director — фото,
   RERA-статус, лет в Дубае, пресс-упоминания (HiDubai, Morning Brew после выхода).
2. Person-схема с `sameAs` (LinkedIn, профиль Qwoted) + `worksFor` → Organization.
3. В Article-схеме блога: `author` → Person для редакционных статей;

4. Байлайн-блок на страницах статей («Reviewed by …» + ссылка на автора).

### B. Bing + IndexNow (нед. 1, ~полдня)
1. Зарегистрировать worldwise.pro в Bing Webmaster Tools (импорт из GSC — минуты).
2. IndexNow-пинг в сайтмап-флоу (Next route или крон-скрипт после публикаций).
3. Через месяц: проверить Copilot/ChatGPT-цитируемость в ai-visibility-логе.

### C. Соцсети × поиск: platform properties + UTM (нед. 1)

**C.0 — GSC platform properties (руками юзера, ~10 мин, сделать ПЕРВЫМ).**
07.07.2026 Google добавил в Search Console новый тип ресурса — «platform
properties» (официальный анонс Search Central; глобально с 29.07): Instagram,
TikTok, X и YouTube подключаются как отдельные ресурсы и показывают клики/показы/
запросы, по которым профиль и посты находят в Google Search/Discover/News.
**Исторические данные не подтягиваются** — счёт идёт с момента подключения,
поэтому подключать сразу, даже если аккаунт почти не ведётся. Подключение —
только вручную (OAuth-логин в соцсеть; Google блокирует вход в
автоматизированном браузере): Search Console → Add property → выбрать платформу
→ авторизовать. Наши: Instagram @worldwiseofficial, YouTube @worldwiserealestate
(выбрать БРЕНД-канал, не личный профиль — та же грабля, что с youtube.mjs),
TikTok @worldwiseestate. X-аккаунта нет — пропустить.

**Разграничение (чтобы не путать инструменты):** platform properties показывают,
как **профили и посты видны в выдаче Google**; UTM+GA4 ниже показывают
**переходы на наш сайт** из соцсетей и доводят их до лида в CRM. Это
дополняющие измерения, а не альтернативы.

**C.1–C.4 — UTM-атрибуция (как было):**
1. Канонические ссылки: `?utm_source=instagram&utm_medium=social&utm_campaign=bio`
   (и аналоги для youtube/dzen/vk/ok/tg). `lib/utm.ts` уже пишет их в лиды —
   в CRM появится атрибуция «лид из Instagram» без единой строчки кода.
2. YouTube: ссылка канала + описания топ-видео через `youtube.mjs apply` (квота
   дешёвая, 50 units/update). Instagram-bio — руками юзера. Дзен — закрыть
   давно висящий utm-фикс лонгридов.
3. GSC ↔ YouTube: связка в YouTube Studio («Associated website», подтверждается
   существующей GSC-верификацией) + Association в GSC. Трафика это не даёт, но
   включает карточки-ссылки на сайт в видео и укрепляет entity-граф бренда.
4. GA4: через 2 недели `ga4.mjs sources` покажет реальный вклад соцсетей.

### D. Ответ-капсулы в автоблоге (нед. 2, ~1 час)
Промпт `generate-article.mjs`: первый абзац = самодостаточный ответ 40–70 слов
без местоимений в первом предложении; в E-E-A-T-гейт — проверку длины первого
абзаца. Даёт извлекаемость для AIO/LLM на всём будущем потоке без ручной работы.

### E. Unlinked mentions (фон, ~час на настройку)
Google Alerts на "Worldwise Real Estate" + "worldwise.pro" → в вахту почты.
Найденное упоминание без ссылки = вежливое письмо с просьбой добавить href
(шаблон в outreach-templates). Первый кандидат уже известен: следить за
переизданиями материала investdubaitoday.

### Ждут решения юзера (не блокируют A–E)
- **Reddit-пилот** (П5, висит с июля): Perplexity цитирует Reddit чаще любого
  другого UGC-источника — рекомендация «да», формат: честные ответы в
  r/dubai / r/DubaiPetrolHeads / r/expats без ссылок в первые недели.
- **GBP-верификация** (видео + часы) — разблокирует local pack и П3-GEO.
- **Живые Shorts** (очередь пуста с 01.08) — видео-компаньоны к citable-активам.

## 4. Чего сознательно НЕ делаем (и почему)
- **Яндекс-SEO** — аудитория сайта англоязычная, мультиязык отклонён; RU-спрос
  обслуживают дистрибуционные платформы.
- **Массовая закупка ссылок / guest-post-сетки** — риск против niche-агентства
  с 9 реф.доменами несоразмерен; только editorial через data-led PR.
- **Погоня за AI-детекторами в питчах** — закрыто уроком 03.08 (Pangram):
  только диктовка юзера.
- **Google Ads** — пауза до сентября (решение 01.07), пересмотр отдельным разбором.
- **Новые типы страниц** (programmatic-SEO на районы×типы и т.п.) — без
  отдельного разбора ценности; текущий контент-поток ещё не исчерпан.
